# 🐰 YumikoToysRR for NIO (iOS) · 二次元智能蔚来看板与灵动岛实时监控

> **YumikoToysRR for NIO** 是一款专为蔚来车主打造的二次元艺术风智能车况看板、灵动岛 (Dynamic Island) 与锁屏实时活动 (Live Activity) 监控助理。

---

## ✨ 核心特性

- 🔋 **全维动力电池诊断与估算**：
  - 高压动力电池 SOC 实时精准电量与满电标称容量推算（支持 75kWh / 100kWh / 150kWh 电池包自动识别）；
  - CLTC 宣传标称续航与实际估算（WLTP 风格真实工况）双模切换；
  - 12V 铅酸 / 磷酸铁锂低压辅助电瓶实时电量百分比与电压监测。
- 📈 **能耗达成率与百公里电耗评分**：
  - 达成率实时智能计算，休眠期无感算法推算；
  - 真实电耗评分、满电实际可用续航预测与节能驾驶评级。
- 🏝️ **灵动岛 (Dynamic Island) 与实时活动 (Live Activity)**：
  - 息屏/锁屏即时查看电量、续航、车锁状态、充电功率与充满倒计时；
  - 展开区直观呈现胎压四联、车内外温差、车载冰箱、守卫模式告警数与车机固件版本；
  - 采用高性能后台节流与去重指纹机制，极低功耗。
- 🔧 **维保周期与耗材寿命追踪**：
  - 空调滤芯、制动液（刹车油）、空调干燥剂、齿轮箱油等维保周期与寿命倒计时。
- 🅿️ **高精停车位置与坐标纠偏**：
  - 高德 GCJ-02 与 WGS-84 地球坐标精准互相校准，一键调用 Apple 地图 / 高德地图寻车。
- ❄️ **座舱舒适与车载电器**：
  - 车载智能冰箱温控、对外放电 (V2L)、守卫模式、宠物模式、露营模式状态全景监控。
- 🎨 **二次元萌动艺术与像素主题**：
  - 内置兔可可专属粉、赛博蓝、暗夜极光等多款艺术主题，支持 120 FPS 丝滑切换与像素开屏动效。

---

## 🛠️ 技术架构

- **UI 框架**：SwiftUI + ActivityKit + WidgetKit
- **架构模式**：MVVM + Clean Architecture
- **兼容性**：iOS 16.1+（支持灵动岛的 iPhone 机型与全系标准刘海 / 灵动岛 iPhone）
